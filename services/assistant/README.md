# Proactive Executive Assistant Service (`services/assistant/`)

> [!NOTE]
> **Generated By**: Gemini (via ai-os)  
> **Audited & Hardened By**: Claude Sonnet

A local-first, context-gated personal executive assistant service embedded directly in `ai-os` (`services/assistant/`). Manages spaced repetition, habit tracking, and micro-interventions via Telegram with offline tolerance, sleep-wake recovery, and empathetic anti-spam behavior.

---

## Key Features

1. **Context Gate (`context_gate/`)**:
   - Evaluates availability before dispatching any notification.
   - **Calendar Probe**: Uses macOS EventKit (with AppleScript fallback) to detect active calendar events, with an automatic `+45m` routine buffer (e.g. piano practice / walk home after university class).
   - **Focus Mode Probe**: Detects active Focus Modes (DND, Driving, Theater) via native macOS Shortcuts / system indicators.
   - **Silence Cooldown**: If a prompt is ignored by Matt, the service records silence as an empathetic signal and backs off completely (default: 2 hours) rather than double-texting or nagging.

2. **Sleep-Wake Recovery (`run.py`)**:
   - Decouples machine sleep (laptop closed) from user unavailability (ignoring a prompt).
   - Tracks **awake monotonic time** only: 6 hours of Mac sleep will never falsely trigger a silence timeout.
   - On wake from sleep:
     - Silently expires stale triggers whose TTL has passed.
     - Picks only the single highest-priority valid item to evaluate.
     - Automatically delays other pending triggers by +30 minutes to prevent alert avalanches upon opening the laptop.

3. **Spaced Repetition (`spaced_repetition/`)**:
   - Driven by the open-source **FSRS** (Free Spaced Repetition Scheduler) algorithm.
   - Partitions decks into:
     - `cold_storage`: Academic coursework and long-term retention (0.90 retention target).
     - `baby_facts`: Trivia and quick factual associations (0.85 retention target).
   - Lightweight micro-dosing format (10–30s recall prompt with inline 1-tap rating buttons: `Again`, `Hard`, `Good`, `Easy`).
   - Progressive elaboration: Edits the Telegram message in-place to reveal the answer, 1-sentence novel application context, and next scheduled review date.

4. **Obsidian Habit Bridge (`habit_bridge/`)**:
   - Zero-database habit definition and daily logging directly into the iCloud Obsidian Personal Vault (`Habits Design.md` schema).
   - Reads habit YAML definitions from `habits/definitions/*.md`.
   - On button press (`[🌟 Full Session]` or `[⚡️ 2-Min Emergency]`), appends completion to `habits/logs/YYYY-MM-DD.md` (updating YAML frontmatter `completed` list and markdown task line).
   - Edits the Telegram prompt in-place to confirm logging with timestamp.

## Directory Structure

```
ai-os/services/assistant/
├── run.py                 # Main event loop & launchd entrypoint (sleep gap detection)
├── config.py              # Configuration dataclass, vault paths, Telegram tokens
├── context_gate/
│   ├── calendar.py        # EventKit query with startup TCC permission self-test
│   ├── focus_mode.py      # Focus check via macOS Shortcuts / supported probe
│   └── evaluator.py       # Combines focus, calendar, +45m routine buffer, awake cooldowns
├── telegram_gateway/
│   ├── bot.py             # python-telegram-bot worker (handles callbacks, edits messages)
│   ├── handlers.py        # FSRS & Habit button dispatchers
│   └── silence.py         # Awake-time silence watchdog (mutes expired prompts)
├── spaced_repetition/
│   ├── engine.py          # fsrs-python wrapper & deck partitioning
│   └── cards.py           # SQLite card retrieval and progressive elaboration formatter
├── habit_bridge/
│   ├── parser.py          # Reads YAML from vault/habits/definitions/*.md
│   └── logger.py          # Appends completion to vault/habits/logs/YYYY-MM-DD.md
├── storage/
│   └── db.py              # aiosqlite queue, FSRS state, and awake-signal ledger
└── tests/
    └── test_assistant.py  # 7-suite unit and integration test coverage
```

## Configuration & Environment Variables

| Variable | Description | Default |
| :--- | :--- | :--- |
| `TELEGRAM_BOT_TOKEN` | Bot API token from `@BotFather` | `None` (Runs in DRY-RUN mode if omitted) |
| `TELEGRAM_CHAT_ID` | Your Telegram user ID | `None` |
| `ASSISTANT_DB_PATH` | Path to persistent SQLite database | `~/.hermes/assistant.db` |
| `OBSIDIAN_VAULT_PATH` | Path to iCloud Obsidian Personal Vault | `~/Library/Mobile Documents/iCloud~md~obsidian/Documents/Personal` |
| `ASSISTANT_DRY_RUN` | Force dry-run simulation mode | `0` |
