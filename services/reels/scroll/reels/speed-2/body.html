01 · Characteristic truth tables · ch. 9

Each connective is just a table

A truth table lists every combination of true and false for the parts, and says what the whole sentence is on each one. Here are all five connectives in one table. This is the one thing to know cold.

𝒜ℬ¬𝒜𝒜 ∧ ℬ𝒜 ∨ ℬ𝒜 → ℬ𝒜 ↔ ℬ
TTFTTTT
TFFFTFF
FTTFTTF
FFTFFTT

Short versions. And is true only when both are true. Or is false only when both are false. The arrow is false only when the left is true and the right is false. The double arrow is true when both sides match.

When is 𝒜 ∨ ℬ false?

The arrow's table surprises people. The book calls it the material conditional: by stipulation, it's false only in that one row, and true in the other three.

P is false and Q is true. What is P → Q?

And, or, and the double arrow are commutative: you can swap the two sides without changing anything. The arrow isn't.

02 · Truth-functional connectives · ch. 10

Only the truth values matter

A connective is truth-functional if the truth value of the whole is fixed by the truth values of its parts and nothing else. All five TFL connectives are. Many English ones aren't.

Take "because". "Matt studied, because he wanted to pass" and "Matt studied, because it was Tuesday" might have all their parts true, yet the first is true and the second false. Knowing the parts are true isn't enough, so "because" is not truth-functional.

Which of these is not truth-functional?

This is why the book says we symbolize English rather than translate it. A symbolization key only promises that each letter has the same truth value as its English sentence. Tone, emphasis and contrast are left behind.

It also explains the odd arrow. Subjunctive conditionals, like "if I had studied, I would have passed", aren't truth-functional, so the arrow handles them badly. TFL's arrow is only a stand-in for the indicative "if".

03 · Complete truth tables · ch. 11

Every row, from the inside out

A complete truth table has one row for every possible valuation of the sentence letters. With one letter that's two rows. Each new letter doubles it.

rows = 2ⁿn letters: 1 → 2, 2 → 4, 3 → 8, 4 → 16.

How many rows does a complete table need for a sentence with the letters J, K, L and M?

The standard layout: the first letter's column goes half true, then half false. The next one halves again. The last letter alternates true, false, true, false. That way no row is missed and no row repeats.

Then work from the inside out. Do the smallest parts first, then the connectives that join them, and finish with the main connective. The main connective's column is the truth value of the whole sentence.

¬(P → Q) ∨ RTry the row P = T, Q = F, R = F. Inside out: first P → Q, then ¬, then ∨.

On the row P = T, Q = F, R = F, what is ¬(P → Q) ∨ R?

One bracket note from this chapter. Chains of only ands, or only ors, give the same table however you group them. Mix different connectives, or chain arrows, and the grouping changes the table, so the brackets matter.

04 · Semantic concepts · ch. 12

Chapter 3's ideas, made checkable

Each idea from chapter 3 gets a TFL version you can test with a table. A tautology is true on every row. A contradiction is false on every row. Anything else is contingent: true on some rows and false on others.

A sentence's main column reads T, F, F, T. It is…

Two sentences are equivalent if their main columns match on every row. A group of sentences is jointly satisfiable if at least one row makes all of them true at the same time.

Three sentences are each true on at least one row, but never on the same row. They are…

Entailment is validity, made checkable. Some sentences entail a conclusion if no row makes all of them true and the conclusion false. A row like that is called a bad row. No bad rows means valid.

Using the table above: does the first sentence entail the second?

The book writes entailment with the double turnstile. It is not a TFL symbol. It belongs to the metalanguage, the English we use to talk about TFL, so a turnstile sentence is a claim about TFL sentences, not another TFL sentence.

With nothing on the left, it says the sentence on the right is true on every row: a tautology. And the turnstile and the arrow are linked. A entails C exactly when A arrow C is a tautology.

05 · Limitations of TFL · ch. 13

Where truth tables give the wrong answer

A truth table only sees letters. "Sam is a sister, so Sam is a sibling" is valid in English, but it becomes two unrelated letters, and the table calls it invalid. TFL can't see the meaning inside a sentence. First-order logic, later in the course, can see more.

“Kim is a bachelor. So Kim is unmarried.” What does a truth-table test say?

The arrow causes trouble too. Any arrow with a false left side counts as true, so some odd English "if" sentences come out true, or entail things they shouldn't. The fix is careful symbolizing, not a new table.

Throwback: a sentence uses the letters A, B and C, and A appears three times. How many rows?

Different letters, not appearances. Now, how to save time.

06 · Shortcuts · ch. 14

Stop filling in a row once you know the answer

You rarely need every cell. An or with one true side is true. An and with one false side is false. An arrow with a true right side, or a false left side, is true. Once one of these happens, skip the rest of that part.

For validity, you only hunt for bad rows. So start with the conclusion. Any row where the conclusion is true can't be bad: skip it. On the rows left, as soon as one premise is false, that row can't be bad either.

You're testing an argument and the conclusion is true on row 3. What do you do with row 3?

Shortcuts change nothing about the answer. They just skip the cells that can't matter.

07 · Partial truth tables · ch. 15

One row, or all of them?

Some claims need just one row as proof. To show a sentence isn't a tautology, find one row where it's false. To show sentences aren't equivalent, find one row where they differ. To show an argument is invalid, find one bad row.

Other claims are about every row, so they need the complete table. That's showing something is a tautology, a contradiction, equivalent, jointly unsatisfiable, or valid.

1 rowNot a tautology · not a contradiction · not equivalent · jointly satisfiable · invalid
2 rowsContingent: one true row and one false row
allTautology · contradiction · equivalent · jointly unsatisfiable · valid

A handy pattern: "some row exists" claims need one row, and "no row exists" claims need them all.

You want to show that a sentence is not a contradiction. What do you need?

One more, the other way round.

You want to show an argument is valid. What do you need?

A contingent sentence needs exactly two rows: one where it's true, one where it's false.
