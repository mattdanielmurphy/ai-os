01 · Extensionality · ch. 30.1–30.2

A predicate is just the things it's true of

The extension of a predicate is the collection of things it's true of. FOL only cares about extensions, not meanings. If two predicates are true of exactly the same things, FOL can't tell them apart. That's why the book calls FOL extensional, and says we symbolize rather than translate.

You can set an extension just by listing things, even things with nothing in common. And an extension can be empty, with nothing in it at all.

In some domain, “x is a vice-captain” and “x wears number 7” happen to be true of exactly the same people. For FOL…

02 · Pairs, identity, interpretations · ch. 30.3–30.5

Two-place predicates take ordered pairs

A two-place predicate's extension is a list of ordered pairs, written in angle brackets. The order matters: the pair Ana, Bo is different from the pair Bo, Ana.

Identity is special. Its meaning is fixed in every interpretation: each thing is identical to itself and to nothing else. Two different things can even share every other predicate and still be two things.

An interpretation has four parts. A domain, which can't be empty. A truth value for each sentence letter. One object in the domain for each name. And an extension for each predicate, except identity, which is already fixed.

Which is not part of an interpretation?

Here's the interpretation we'll use for the next few questions. Read it carefully.

a: Ana

03 · Truth in FOL · ch. 31

All means every object, some means at least one

Atomic sentences are true when the named objects, in order, are in the predicate's list. The connectives work exactly as in TFL. A for-all sentence is true when every object in the domain satisfies the formula after the quantifier. A there-is sentence is true when at least one object does.

The book makes this precise with new names. To check a for-all sentence, imagine giving a fresh name to each object in turn, and check every one of those instances. For there-is, you only need one instance to come out true.

Same interpretation. Is ∀x F(x) true?

Now a there-is one.

Is ∃x (F(x) ∧ G(x)) true?

Two quantifiers, same game. Every object must have a partner for for-all, there-is. One object must work for everyone for there-is, for-all.

Is ∃y ∀x L(x, y) true? (Is someone L'd by everyone?)

Yet for-all-x, there-is-y, L of x y is true here. Ana points to Bo, Bo to Bo, Cy to Ana. Everyone points to someone, but no one is pointed to by all. Order matters, again.

04 · Semantic concepts · ch. 32

Reel 2's ideas, with interpretations instead of rows

Swap "row" for "interpretation" and the definitions carry over. A validity is true in every interpretation: it's FOL's version of a tautology. A contradiction is false in every one. An argument is valid if no interpretation makes the premises true and the conclusion false. Equivalent means same truth value in every interpretation. Jointly satisfiable means some interpretation makes them all true.

An FOL sentence is true in every interpretation. It is…

A formula with free variables can't be true or false, but objects can satisfy it. That lets a formula express a relation the key has no letter for. With a key for "x trains y", the formula there-is-z, z trains x and z trains y, expresses "x and y share a trainer".

05 · Using interpretations · ch. 33

One counter-interpretation is enough to say no

To show a sentence is not a validity, give one interpretation where it's false. To show it's not a contradiction, give one where it's true. To show an argument is invalid, give one where the premises are true and the conclusion is false. That's a counter-interpretation, or counter-model.

Tip from the book: keep the domain tiny, often one or two objects, and pick extensions that do exactly what you need.

∃x L(x, a) ∴ L(a, a)Invalid. Find premises true, conclusion false.

Domain: Ana, Bo. a: Ana. Which extension for L shows that argument is invalid?

One caution. A counter-model to the symbolized argument doesn't prove the English argument is invalid. "Every fox is cute, so every vixen is cute" is valid in English, but FOL can't see that vixens are foxes unless you add it as a premise.

06 · Reasoning about all interpretations · ch. 34

Saying yes is harder than saying no

To show a sentence is a validity, checking many interpretations isn't enough, because there are infinitely many. You have to reason, in English, about an arbitrary interpretation: pick any one, and show the sentence must be true in it.

oneNot a validity · not a contradiction · not equivalent · satisfiable · invalid

Same pattern as partial truth tables: "there is one" claims need one example. "There is none" claims need an argument about all of them. The difference is that truth tables are finite, and interpretations aren't.

07 · Properties of relations · ch. 35

Reflexive, symmetric, transitive

"Ana is taller than Bo, Bo is taller than Cy, so Ana is taller than Cy" is valid in English, but not in FOL as it stands. It relies on a property of "taller than": transitivity. Add transitivity as a premise and the FOL argument becomes valid.

reflexiveEverything bears it to itself.
symmetricWhenever it holds one way, it holds the other way too.
transitiveIt chains: x to y and y to z gives x to z.
anti-symmetricNever both ways between two different things.
reflexive∀x R(x, x)
symmetric∀x ∀y (R(x, y) → R(y, x))
transitive∀x ∀y ∀z ((R(x, y) ∧ R(y, z)) → R(x, z))

A relation that is reflexive, symmetric and transitive is an equivalence relation. One that is reflexive, transitive and anti-symmetric is a partial order.
