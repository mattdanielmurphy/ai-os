01 · Why we need more than TFL

Truth tables can't see inside a sentence

Take this argument. Every cat purrs. Mo is a cat. So Mo purrs. Anyone can see it's valid.

In truth-functional logic, the logic of Units 2 to 4, each of those sentences becomes one capital letter. You get P, Q, therefore R. A truth table calls that invalid, because R could be false while P and Q are true.

P, Q ∴ R∴ means “therefore”. Each letter is a whole sentence, so TFL loses the link between them.

Nothing was symbolized wrong. TFL simply can't look inside a sentence, so it can't see that two of them are about cats. First-order logic, or FOL, splits each sentence into smaller pieces, so it can.

02 · The pieces

Four new kinds of symbols

Here is every new piece in one table. The rest of this reel uses only these, so come back to the table whenever a symbol looks strange.

a b c … rNames. Lowercase a to r. Each one picks out exactly one thing, like m for Mo.
C(x)Predicates. Capital letters with a gap. C(x) could mean “x is a cat”.
s t … x y zVariables. Lowercase s to z. Placeholders, not names.
∀“For all”. The universal quantifier: an upside-down A, for All.
∃“There is at least one”. The existential quantifier: a backwards E, for Exists.
¬ ∧ ∨ → ↔Connectives, same as TFL: not, and, or, if-then, if and only if.

A name works like a proper name: the letter m might stand for Mo. A predicate is a sentence with a hole in it, like "blank is a cat". Put a name in the hole and you get a whole sentence.

C(m)“Mo is a cat.” The predicate comes first, then the name in brackets. Read it “C of m”.

So "Mo is a cat" becomes capital C, with m in brackets. All the old connectives still work, so "Mo is a cat and Mo purrs" is C of m, and, P of m.

C(m) ∧ P(m)“Mo is a cat and Mo purrs.”

Variables are the letters near the end of the alphabet, s to z. They don't name anything. They are placeholders, waiting for a quantifier to tell us how to fill them in.

03 · The two quantifiers

For all, and there is

The upside-down A means "for all". Write it, then a variable, then say something about that variable. "For all x, x purrs" says that everything purrs.

∀x P(x)“Everything purrs.” Read: for all x, P of x.

The backwards E means "there is at least one". "There is an x such that x purrs" says something purrs. At least one thing does, maybe many.

∃x P(x)“Something purrs.” Read: there is an x such that P of x.

The letter x isn't special. "For all y, P of y" says exactly the same thing. The variable only links the quantifier to the gap it fills.

Which one says “Something is a cat”?

04 · The domain

What "everything" means

Every symbolization starts with a key: what each letter means, plus a domain. The domain is the collection of things we're talking about. "For all" means everything in the domain, not everything in the universe.

Symbolization keydomain: animals in Mo's house
C(x): x is a cat
P(x): x purrs
m: Mo

With this key, "for all x, P of x" means every animal in Mo's house purrs. Nothing outside the house counts.

Two rules about domains. A domain always has at least one thing in it. And every name must pick out exactly one thing in the domain. One thing can have several names, or no name at all.

That's why a name can't stand for something that doesn't exist, like a unicorn. If you want to talk about unicorns, put them in the domain, for example a domain of creatures in stories.

05 · Not, with a quantifier

A "not" flips all into some

"No one is angry" can be written two ways. "It's not true that someone is angry." Or, "everyone is not angry." Both are correct, and they mean the same thing.

not some¬∃x A(x)
all not∀x ¬A(x)
Both say “No one is angry.” Domain: people.

In the same way, "not everyone is happy" means the same as "someone is not happy".

not all¬∀x H(x)
some not∃x ¬H(x)
Both say “Not everyone is happy.”

An easy way to remember it: moving a "not" across a quantifier flips the quantifier. All becomes some, and some becomes all.

06 · The four patterns

Every, some, no, and only

Most English sentences with one quantifier fit one of four patterns. Learn these four and you can handle most of chapter 24. Here's a key about animals at a shelter.

Symbolization keydomain: animals at the shelter
D(x): x is a dog
K(x): x is a kitten
B(x): x barks
S(x): x is asleep

Pattern one. "Every dog barks." Paraphrase it as: take anything at all; if it's a dog, then it barks. That if-then is the key. Every F is G becomes: for all x, if F of x, then G of x.

∀x (D(x) → B(x))“Every dog barks.” The upside-down A goes with the arrow.

Why not "and"? "For all x, D of x and B of x" says every animal is a dog, and every animal barks. The kittens would have to be barking dogs. That's far too strong.

∀x (D(x) ∧ B(x))Says every animal at the shelter is a barking dog. Wrong.

Pattern two. "Some dog barks." There's at least one thing that is a dog and barks. Some F is G becomes: there is an x such that F of x and G of x.

∃x (D(x) ∧ B(x))“Some dog barks.” The backwards E goes with “and”.

Why not an if-then here? "There is an x such that if it's a dog, it barks" comes out true as soon as there's one animal that isn't a dog, like a kitten. Remember, an if-then with a false "if" part is true. So it says almost nothing.

∃x (D(x) → B(x))True as soon as anything is not a dog. Far too weak.
Rule of thumb: all goes with the arrow, and some goes with "and".

Which says “Some kitten is asleep”?

Pattern three. "No dog is asleep." Two good ways again. It's not true that some dog is asleep. Or: for all x, if x is a dog, then x is not asleep.

not some¬∃x (D(x) ∧ S(x))
all not∀x (D(x) → ¬S(x))
Both say “No dog is asleep.”

Pattern four. "Only dogs bark." The trick with "only" is to ask when the sentence would be false. It's false if something barks and isn't a dog. So it says: for all x, if x barks, then x is a dog.

∀x (B(x) → D(x))“Only dogs bark.” The word right after “only” goes after the arrow.

Notice the order flipped. "Only F's are G" becomes: for all x, if G of x, then F of x. The word that comes right after "only" goes after the arrow.

Which says “Only kittens are asleep”?

every F is G∀x (F(x) → G(x))
some F is G∃x (F(x) ∧ G(x))
no F is G¬∃x (F(x) ∧ G(x))  or  ∀x (F(x) → ¬G(x))
only Fs are G∀x (G(x) → F(x))
The four patterns on one card. Worth knowing cold for the midterm.

07 · Empty predicates

"Every unicorn" can be true

A predicate is allowed to be true of nothing at all. Say U of x means x is a unicorn, and the domain is the shelter animals. There are no unicorns there, so U is an empty predicate.

Now take "every unicorn is asleep": for all x, if U of x, then S of x. It's true! Every "if" part is false, so every if-then is true. Logicians call this vacuously true. But "some unicorn is asleep" is false, because there's no unicorn to do the sleeping.

true, vacuously∀x (U(x) → S(x))
false∃x (U(x) ∧ S(x))
With no unicorns in the domain.

So "every F is G" doesn't promise that there are any F's. That surprises almost everyone the first time.

08 · Picking a domain

Who counts as "everyone"

The domain changes how you write things. If the domain is only people, "everyone is tired" is simply: for all x, T of x. If the domain has people and pets in it, you need: for all x, if x is a person, then x is tired.

domain: people∀x T(x)
domain: people and pets∀x (P(x) → T(x))
Both say “Everyone is tired.” P(x): x is a person.

A small domain saves writing, but it has to include everything your sentences talk about.

09 · Paraphrase and scope

"She" can hide an "everyone"

"If Ada is a drummer, then she is loud" is about one person, Ada. It's a plain if-then with a name: D of a, arrow, L of a.

D(a) → L(a)a: Ada · D(x): x is a drummer · L(x): x is loud

But "if a person is a drummer, then she is loud" is about everyone. Paraphrase it first: for any person x, if x is a drummer, then x is loud.

∀x (D(x) → L(x))Domain: people. Paraphrasing into “for any x, if…” first makes the symbols easy.

How much of a sentence a quantifier covers is called its scope, and the brackets show it. Moving a bracket can change the meaning, so always check what the brackets wrap around.

∀ covers only D(x)∀x D(x) → L(a)
∀ covers the whole if-then∀x (D(x) → L(a))
Top: if everyone is a drummer, Ada is loud. Bottom: if anyone is a drummer, Ada is loud.

Wrap-up

What to remember

  1. Names are a to r, variables are s to z, predicates are capitals with gaps.
  2. All goes with the arrow, some goes with "and".
  3. "No" is "not some", and "only" flips the arrow.
  4. The domain decides what "everything" means.

Last one. Which says “No kitten barks”?
