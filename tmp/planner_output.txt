## The core design
- **State layer**: new `config/rules.state.json` — sparse overrides map, never edits rule `.md` content directly.
- **Compile layer**: `build_rules.py` gets a `filter_enabled_fragments()` step that excludes disabled rules (whole-file or anchor-delimited sub-block) before compiling the prompt, with a self-documenting `DISABLED RULES:` banner comment.
- **Command layer**: new `/rule` slash command (`on`/`off`/`list`/`status`/`reset`) intercepted in `apps/aios-tui` (and/or `bin/ai-os`), backed by a new canonical `scripts/rule_toggle.py` CLI that both the TUI and any script can call — toggles persist until explicitly flipped back, no auto-expiry, per your requirement.
- **Generalization**: a parallel `features.state.json` pattern for non-rule settings (e.g., extreme-delegation default, quota thresholds) as a fast-follow, using the same store pattern.
