## Key Architectural Decision

The core problem both action items share is that gemini.google.com runs in a **remote-origin webview**, so Tauri's IPC isn't exposed there by default. The plan resolves this with Tauri v2's `dangerousRemoteDomainIpcAccess` config scoped strictly to `gemini.google.com`, plus a new capability file limiting exactly which commands are exposed — not a blanket IPC open-door.

## Agentic Loop Without Native Function-Calling

Since Gemini's web UI has no tool-calling hooks, the plan defines a **fenced-block action protocol** (` ```bridge-action `) that a `MutationObserver` in a new `gemini-context-bridge.js` module scans for, executes through the Rust bridge, and feeds results back into the compose box as the next turn — closing the loop entirely at the DOM layer.
