This implementation plan outlines the automated orchestration workflow to ingest relevant Gemini discussion threads, extract and stage the candidate resume, initialize a tracking repository, and execute parallel evaluation and outreach tracking pipelines.

## Architectural Strategy

The orchestration pipeline follows an **event-driven** multi-stage execution model designed to move from unorganized context to an operational job search system in minutes.

The system is decoupled into four sequential execution phases:
- Thread Extraction and Sanitization: Scans Hermes SQLite session state (`~/.hermes/state.db`) and Antigravity execution transcripts (`~/.gemini/antigravity-cli/brain/`) for conversation turns discussing job search strategies, sanitizing tool calls and internal reasoning blocks into pure conversational Markdown.
- Resume Ingestion and Document Structuring: Ingests `/Users/matt/projects/job-applier/Darryl Murphy CV - Aug 12, 26 (Construction Superintendent - Brunel).docx`, parses plain text and structural blocks, and creates the baseline markdown dossier mapped against the 11 target construction and quality management roles.
- Repository Initialization: Initializes a structured Git repository, creates necessary documentation boundaries, commits sanitized threads and resume files, and links the remote GitHub repository via the authenticated GitHub connector.
- Parallel LLM Dispatch: Issues two asynchronous, concurrent requests to Gemini Flash (one tailored for resume critique across target roles, and one for a lightweight, zero-overhead LinkedIn outreach and follow-up CRM).

## Data Structures and State

The orchestrator utilizes typed state representations to ensure deterministic data transfer between extraction, parsing, repository synchronization, and external API prompts.

```python
from dataclasses import dataclass, field
from enum import Enum
from typing import List, Dict, Optional
from datetime import datetime

class RoleCategory(str, Enum):
    CONSTRUCTION_LEAD = "Construction Management / Superintendent"
    QUALITY_ASSURANCE = "QA/QC Management & Advisory"
    PROJECT_CONTROLS = "Project Management & Coordination"
    ELECTRICAL_SPECIALTY = "Electrical Superintendent / PM"

@dataclass
class TargetRoleProfile:
    title: str
    category: RoleCategory
    core_competencies: List[str]

@dataclass
class ConversationExchange:
    role: str  # "user" | "assistant"
    content: str
    timestamp: Optional[datetime] = None

@dataclass
class ExtractedThread:
    thread_id: str
    source: str  # "hermes_db" | "gemini_cli"
    title: str
    exchanges: List[ConversationExchange]
    created_at: datetime

@dataclass
class CandidateProfile:
    raw_resume_path: str
    extracted_text: str
    structured_sections: Dict[str, str]
    target_roles: List[str]

@dataclass
class OutreachContact:
    name: str
    company: str
    title: str
    linkedin_url: Optional[str]
    relationship_context: str
    last_contact_date: Optional[str]
    next_follow_up_date: Optional[str]
    status: str  # "Identified", "Message Sent", "Follow-up Due", "Meeting Booked"
    notes: str

@dataclass
class OrchestrationState:
    workspace_dir: str
    repo_name: str
    extracted_threads: List[ExtractedThread] = field(default_factory=list)
    candidate_profile: Optional[CandidateProfile] = None
    evaluation_result: Optional[str] = None
    outreach_plan_result: Optional[str] = None
    created_files: List[str] = field(default_factory=list)
```

## Interface Contracts and Signatures

The orchestrator interface is partitioned into four decoupled modules: thread extraction, document processing, repository management, and parallel model execution.

```python
from abc import ABC, abstractmethod
from typing import List, Dict, Tuple, Any

class IThreadExtractor(ABC):
    @abstractmethod
    def search_relevant_threads(self, query_keywords: List[str]) -> List[Dict[str, Any]]:
        """Queries Hermes SQLite and Antigravity logs for matching job search threads."""
        pass

    @abstractmethod
    def sanitize_transcript(self, raw_messages: List[Dict[str, Any]]) -> List[ConversationExchange]:
        """Strips tool invocations, internal thoughts, and CLI metadata to keep pure dialogue."""
        pass

    @abstractmethod
    def export_thread_markdown(self, thread: ExtractedThread, output_path: str) -> str:
        """Writes sanitized exchange list into a standard span-compliant Markdown document."""
        pass


class IDocumentProcessor(ABC):
    @abstractmethod
    def parse_docx_resume(self, file_path: str) -> CandidateProfile:
        """Extracts text, headers, and bullet structures from the candidate's docx CV."""
        pass

    @abstractmethod
    def generate_role_matrix_md(self, profile: CandidateProfile, target_roles: List[str], output_path: str) -> str:
        """Generates target-role mapping file linking existing experience to the 11 target positions."""
        pass


class IRepositoryManager(ABC):
    @abstractmethod
    def initialize_local_repo(self, repo_dir: str) -> bool:
        """Initializes git repo, sets up .gitignore, and stages base files."""
        pass

    @abstractmethod
    def create_remote_repo(self, repo_name: str, private: bool = True) -> str:
        """Invokes GitHub connector to provision a new remote repository."""
        pass

    @abstractmethod
    def push_to_remote(self, repo_dir: str, remote_url: str, branch: str = "main") -> bool:
        """Commits all staged markdown artifacts and pushes to the default branch."""
        pass


class IModelEvaluator(ABC):
    @abstractmethod
    async def evaluate_resume(self, resume_content: str, target_roles: List[str]) -> str:
        """Calls Gemini Flash to generate constructive role-specific resume improvements."""
        pass

    @abstractmethod
    async def generate_quickstart_outreach_plan(self, resume_summary: str, target_roles: List[str]) -> str:
        """Calls Gemini Flash in parallel to create the lightweight contact tracker and messaging templates."""
        pass
```

## Orchestrator Logic Flow

The end-to-end execution flow executes synchronously through file staging and repository setup, followed by concurrent asynchronous API requests for downstream intelligence.

```python
# Pseudo-code Orchestrator Execution Flow

async def run_job_search_orchestrator(
    resume_path: str,
    target_roles: List[str],
    workspace_dir: str,
    repo_name: str
) -> OrchestrationState:
    
    state = OrchestrationState(workspace_dir=workspace_dir, repo_name=repo_name)
    
    # Step 1: Thread Discovery and Sanitization
    keywords = ["job search", "construction superintendent", "resume", "Darryl", "outreach"]
    raw_threads = thread_extractor.search_relevant_threads(keywords)
    
    for raw in raw_threads:
        sanitized_exchanges = thread_extractor.sanitize_transcript(raw["messages"])
        thread = ExtractedThread(
            thread_id=raw["id"],
            source=raw["source"],
            title=raw["title"],
            exchanges=sanitized_exchanges,
            created_at=raw["timestamp"]
        )
        state.extracted_threads.append(thread)
        out_file = f"{workspace_dir}/threads/{raw['slug']}.md"
        thread_extractor.export_thread_markdown(thread, out_file)
        state.created_files.append(out_file)
        
    # Step 2: Parse Candidate Resume and Build Role Matrix
    profile = doc_processor.parse_docx_resume(resume_path)
    state.candidate_profile = profile
    matrix_file = f"{workspace_dir}/docs/TARGET_ROLES_MATRIX.md"
    doc_processor.generate_role_matrix_md(profile, target_roles, matrix_file)
    state.created_files.append(matrix_file)
    
    # Step 3: Scaffold Lightweight LinkedIn Tracker
    tracker_file = f"{workspace_dir}/docs/LINKEDIN_CONTACT_TRACKER.md"
    scaffold_contact_tracker_template(tracker_file)
    state.created_files.append(tracker_file)
    
    # Step 4: Initialize Git Repository and Push
    repo_manager.initialize_local_repo(workspace_dir)
    remote_url = repo_manager.create_remote_repo(repo_name=repo_name, private=True)
    repo_manager.push_to_remote(repo_dir=workspace_dir, remote_url=remote_url)
    
    # Step 5: Parallel Dispatch to Gemini Flash
    eval_task = model_evaluator.evaluate_resume(
        resume_content=profile.extracted_text,
        target_roles=target_roles
    )
    plan_task = model_evaluator.generate_quickstart_outreach_plan(
        resume_summary=profile.structured_sections.get("Summary", profile.extracted_text[:1000]),
        target_roles=target_roles
    )
    
    # Await both parallel calls
    resume_feedback, outreach_plan = await asyncio.gather(eval_task, plan_task)
    
    # Step 6: Persist AI Outputs into Repository
    feedback_file = f"{workspace_dir}/docs/RESUME_CRITIQUE_AND_RECOMMENDATIONS.md"
    write_file(feedback_file, resume_feedback)
    
    plan_file = f"{workspace_dir}/docs/OUTREACH_EXECUTION_PLAYBOOK.md"
    write_file(plan_file, outreach_plan)
    
    # Commit final documentation
    repo_manager.push_to_remote(repo_dir=workspace_dir, remote_url=remote_url)
    
    return state
```

## Implementation Steps and Edge Cases

The following concrete tasks must be executed in strict order across workspace files:

- Step 1: Create Extraction Utility (`tools/extract_job_threads.py`). Query SQLite Hermes state database at `~/.hermes/state.db` using query `SELECT * FROM sessions WHERE content LIKE '%job%' OR content LIKE '%resume%'` and Antigravity transcripts in `~/.gemini/antigravity-cli/brain/*.jsonl`. Strip regex patterns for `<thought>.*?</thought>` and `tool_call` blocks.
- Step 2: Create Resume Parsing Utility (`tools/parse_resume.py`). Use `python-docx` to extract raw paragraphs and heading hierarchies from `/Users/matt/projects/job-applier/Darryl Murphy CV - Aug 12, 26 (Construction Superintendent - Brunel).docx`. Save parsed markdown into `docs/Darryl_Murphy_Base_CV.md`.
- Step 3: Scaffold Workspace Directory Structure (`job-search-hub/`). Build directory layout:
  - `threads/`: Sanitized historical Gemini conversations.
  - `docs/`: Resume baseline, role matrix, and outreach tracker.
  - `outreach/`: Message templates and company contact logs.
  - `README.md`: Index linking all documents and role priorities.
- Step 4: Automate GitHub Remote Creation and Commit (`tools/git_sync.py`). Call GitHub connector tool `create_repository` with `name="darryl-career-transition"`, `private=True`, initialize local git tracking, and perform initial commit.
- Step 5: Dispatch Parallel Prompts (`tools/run_parallel_advisors.py`). Execute concurrent calls targeting Gemini Flash:
  - Call 1 (Resume Evaluation): Analyze candidate experience against the 11 target titles, identifying impact metrics, safety certifications, and ATS keyword gaps.
  - Call 2 (Outreach Strategy): Generate 3 lightweight LinkedIn message templates (cold connection, former colleague reconnect, recruiter reach-out) and a 3-day follow-up cadence rule.
- Step 6: Stage Outputs and Update Board (`scripts/finalize_run.py`). Write AI outputs to `docs/RESUME_CRITIQUE_AND_RECOMMENDATIONS.md` and `docs/OUTREACH_EXECUTION_PLAYBOOK.md`, push to GitHub, and log completion to `PROJECT_BOARD.md`.

### Error Handling and Edge Cases

- Missing or Locked Docx File: Verify file accessibility before parsing. If file lock is detected, make an in-memory copy to a temporary directory before parsing.
- Malformed Thread Transcripts: Some CLI sessions contain nested JSON logs; enforce fallback line-by-line JSON parsing with exception logging so single malformed entries do not fail the entire export.
- GitHub Name Collision: If the target repository name already exists, append a timestamp suffix (e.g., `darryl-career-transition-20260817`) and update git remote URLs accordingly.
- LinkedIn Outreach Over-Engineering: Enforce markdown-based tracking to avoid database configuration delays; keep outreach templates under 75 words to maximize response rates on mobile.
