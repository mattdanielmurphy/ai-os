Antigravity IDE fails to surface injected conversation threads because the sidebar does not parse raw conversation database files or disk directories directly; instead, it renders history from a dual-index architecture in `state.vscdb` filtered by normalized workspace URIs. To restore visibility, conversation files must be formatted as valid trajectory protobufs, encoded as Base64 payloads under `antigravityUnifiedStateSync.trajectorySummaries`, mirrored in JSON format under `chat.ChatSessionStore.index`, and bound to matching workspace paths.

## Architecture and Storage Comparison

Antigravity.app (legacy standalone runner) and Antigravity IDE (VS Code/Electron harness) diverge significantly in how they persist, index, and query trajectory histories.

| Dimension | Antigravity.app (Classic) | Antigravity IDE (VS Code Fork) |
| :--- | :--- | :--- |
| **Primary State DB** | `~/Library/Application Support/Antigravity/User/globalStorage/state.vscdb` | `~/Library/Application Support/Antigravity IDE/User/globalStorage/state.vscdb` |
| **Workspace Scoping** | Global flat list without workspace partitioning | Scoped to `workspaceStorage/<hash>/state.vscdb` and strict `workspaceUri` matching |
| **Conversation Payloads** | `~/.gemini/antigravity/conversations/*.pb` or `.db` logs | `~/.gemini/antigravity-ide/conversations/<uuid>.pb` Protobuf binaries |
| **Global Summary Index** | `agyhub_summaries_proto.pb` file on disk | `antigravityUnifiedStateSync.trajectorySummaries` (Base64 Proto in SQLite) |
| **Sidebar Session Index** | Optional / decoupled UI list | `chat.ChatSessionStore.index` (JSON array in SQLite) |
| **Query Mechanism** | File scanner reads `.pb` summaries directly | SQLite `ItemTable` query on launch + live in-memory state sync |

The failure occurred due to four missing linkages:
- Conversation persistence expects binary Protobuf files serialized as `TrajectoryProto` at `<uuid>.pb`, not SQLite `.db` tables.
- In `state.vscdb`, `ItemTable` requires Base64-encoded Protobuf strings rather than raw disk paths or unencoded protobuf byte dumps.
- The VS Code chat container requires companion records inside `chat.ChatSessionStore.index` containing session metadata matching the UUIDs.
- The trajectory protobuf contains an explicit `workspaceUri` (field 9) that must match the exact URL-normalized path of the open project (e.g., `file:///Users/matt/projects/ai-os`).

## Data Schemas and State Management

State rehydration requires synchronizing three specific data models across disk and SQLite tables.

```protobuf
// TrajectorySummariesProto schema for state.vscdb ItemTable
message TrajectorySummariesProto {
  repeated TrajectorySummary summaries = 1;
}

message TrajectorySummary {
  string trajectory_id = 1;         // UUIDv4 matching <uuid>.pb file name
  string title = 2;                 // Human-readable conversation title
  int64 created_timestamp_ms = 3;   // Unix epoch milliseconds
  int64 updated_timestamp_ms = 4;   // Unix epoch milliseconds
  int32 turn_count = 5;             // Total user/assistant exchange turns
  string model_name = 6;            // e.g. "gemini-2.5-pro" or "claude-3-7-sonnet"
  string status = 7;                // e.g. "COMPLETED", "IDLE"
  string workspace_uri = 9;         // file:///Users/matt/projects/ai-os
}
```

```typescript
// VS Code Session Store Schema (chat.ChatSessionStore.index)
interface ChatSessionStoreEntry {
  sessionId: string;                // Must match trajectory_id UUID
  title: string;                    // Title displayed in tree view
  creationDate: number;             // Timestamp in ms
  lastMessageDate: number;          // Timestamp in ms
  isImported?: boolean;             // Set true for externally bridged sessions
  initialLocation: "panel" | "editing-session";
}

interface ChatSessionStoreIndex {
  version: number;                  // Typically 1
  sessions: ChatSessionStoreEntry[];
}
```

## Execution Logic and Pipeline Algorithm

The sync pipeline executes four synchronous stages to guarantee transaction consistency and prevent Antigravity IDE launch overwrites.

```text
Algorithm: Antigravity Trajectory Rehydration Pipeline

1. Process Lock & Pre-flight Inspection
   a. Check if "Antigravity IDE" or "antigravity" process is active; prompt termination if running.
   b. Locate global storage: ~/Library/Application Support/Antigravity IDE/User/globalStorage/state.vscdb.
   c. Create timestamped backup of state.vscdb.

2. Protobuf File Ingestion & Compilation
   a. Scan input source directories (~/.gemini/antigravity/brain/, ~/.hermes/state.db, or .db files).
   b. For each conversation:
      i. Extract conversation UUID, exchanges, metadata, and timestamps.
      ii. Serialize message blocks into TrajectoryProto.
      iii. Write binary payload to ~/.gemini/antigravity-ide/conversations/<uuid>.pb.

3. Global Database Synchronization
   a. Open SQLite connection to state.vscdb.
   b. Fetch current value of 'antigravityUnifiedStateSync.trajectorySummaries'.
   c. Decode existing Base64 payload into TrajectorySummariesProto message.
   d. Upsert newly compiled trajectories, enforcing normalized workspace URI (file:// + absolute path).
   e. Re-serialize message to bytes, Base64-encode, and write back to ItemTable.
   f. Fetch current value of 'chat.ChatSessionStore.index'.
   g. Parse JSON array; append missing ChatSessionStoreEntry objects.
   h. Write updated JSON string to ItemTable.

4. Workspace Index Reconcile & Verify
   a. Compute workspace MD5 storage hash or locate matching workspaceStorage/<hash>/workspace.json.
   b. If workspace state.vscdb exists, verify session keys are present.
   c. Run PRAGMA integrity_check and commit transaction.
```

## Edge Cases and Implementation Steps

### Edge Cases and Failure Handling
- **Workspace URI Encoding Mismatches:** File URIs on macOS must be normalized (e.g., standard `file:///Users/...` without double-slashes or unencoded non-alphanumeric chars) to prevent sidebar exclusion filters.
- **Database Lock Collision:** `state.vscdb` uses SQLite WAL mode. If Antigravity IDE is open during injection, changes will be dropped or overwritten on graceful shutdown. The injector must verify file locks before execution.
- **Orphan Protobuf Dropping:** If a `.pb` file exists on disk but is omitted from `chat.ChatSessionStore.index`, the UI ignores it. Both indices must be updated in a single atomic script transaction.

### Ordered Implementation Steps
- Create `scripts/antigravity_storage_migrator.py` implementing `TrajectoryConverter` and `AntigravityStateInjector`.
- Update `scripts/sync_threads.py` to trigger `antigravity_storage_migrator.py` during periodic sync runs.
- Add trajectory proto definitions under `crates/aios-core` or `scripts/proto/trajectory.proto` to ensure standardized serialization.
- Integrate a preflight process check verifying that Antigravity IDE is closed before running automated state modifications.
- Add unit tests in `tests/test_antigravity_storage_migrator.py` validating protobuf Base64 encoding and JSON session index format compatibility.
