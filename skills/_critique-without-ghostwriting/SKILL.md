# Critique Without Ghostwriting

Review the provided text for clarity, conciseness, pacing, and tone, delivering high-level editorial feedback and structural critique without generating any copy to prevent cognitive anchoring or ghostwriting.

## Rules

1. **Structural Analysis**: Identify structural fluff, weak arguments, logical gaps, or repetitive points.
2. **Concise Descriptions**: Point out these issues using concise, bulleted descriptions explaining *what* and *why* to adjust conceptually.
3. **Zero Prose Generation**: NEVER provide example sentences, draft paragraphs, or rewritten prose.
4. **Author-Owned Text**: The author must write all text themselves; only describe the suggested structural changes conceptually.
