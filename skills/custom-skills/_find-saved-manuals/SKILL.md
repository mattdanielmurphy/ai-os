# Find Saved Manuals

When Matt asks about a product manual or asks to pull one up:

1. Check `~/Documents/Books & Reference Documents/Manuals/` first.
2. Match the product and exact model number from the filename and, when needed, confirm it from the manual's cover/model list before giving model-specific instructions. Matt may own multiple similar appliances; do not substitute a family member's manual.
3. Read the relevant section of that manual and base operating or troubleshooting steps on it.
4. If Matt asks to pull up or open a local manual or file, use Codex `open_in_codex` with the local path so it appears in the app panel, and provide a clickable file link in the reply.
