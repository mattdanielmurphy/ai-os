# Repository Context & Domain Knowledge

## Project Overview
`ai-os` is a local-first AI harness designed to transform a macOS machine into an editable, interactive database of thoughts, files, and automation.

## Core Directories & Structure
- `/apps`: Monorepo applications:
  - `/apps/gemini-companion`: Dedicated Tauri shell for Gemini/Perplexity webview automation + IPC loopback daemon.
  - `/apps/aios-tui`: Headless terminal UI harness (Ratatui/Crossterm).
- `/crates`: Shared Rust libraries:
  - `/crates/aios-core`: Headless PTY, session, and thread tracking library.
- `/services`: Background daemons (`agy-proxy`, `clinical-trials`, etc.).
- `/tools`: Standalone helper tools.
- `/bin`: Wrapper scripts and orchestrator binaries (`ai-os`, `ai-os-wiki`, `triage`).
- `/docs`: Architecture, vision, memory, and strategy documentation.
- `/scripts`: Tool helper scripts.
- `/agent-logs`: Session engineering logs.
- `/DEVELOPMENT_JOURNAL.md`: Human-readable timeline of key decisions.

- **Dual-Rail Google Grid:** Seamlessly rotates Google accounts/authentication to double task quotas and VM limits.

- **Gemini Userscript is GENERATED (DO NOT EDIT):** `~/projects/ai-os/userscripts/gemini-DO-NOT-EDIT.js` is a symlink to the generated `~/projects/userscript-bundler/compiled/gemini-enhancements.user.js`. Its real source is the numbered modules in `~/projects/userscript-bundler/userscripts/gemini-enhancements/`. - **Hermes Thread Sync Daemon:** Integrates and synchronizes CLI/GUI NDJSON execution logs (`~/.gemini/antigravity-cli/brain/`) with Hermes' FTS5-enabled SQLite database (`~/.hermes/state.db`) bidirectionally. It launches as a background subprocess via the `bin/ai-os` execution wrapper, maintaining a unified search history across both platforms.
- **One-Way Skill Sync (`watch_skills.sh` & `sync_skills.py`)**: `~/projects/ai-os/skills/` is the only AI-OS-owned source. The watcher distributes source changes to runtime-specific roots: `~/.agents/skills` (Codex/ChatGPT), `~/.gemini/config/skills` (Antigravity IDE), `~/.gemini/antigravity-cli/skills` (Antigravity CLI), and Hermes/Claude/agy roots. It never imports target-only vendor skills. Source deletions are propagated only when target content still matches the last SHA-256 source snapshot; modified files and legacy state without a hash are preserved. Do not sync to the deprecated `~/.gemini/antigravity/skills` compatibility root because it duplicates the current IDE root.
- **Hermes System Prompt Handoff**: Enabled the `agymcp` server to dynamically extract the active Hermes system prompt from `~/.hermes/state.db` and prepend it to prompts sent to `agy` (via `agy`, `agy_continue`, and `agy_start`) to align instructions and preserve behavioral consistency during task handoffs.

Antigravity IDE's language server is a vendor-owned bidirectional stdio protocol and must never be wrapped, delayed, stdin-buffered, or prompt-intercepted; all IDE requests must go directly to Antigravity's native binary and cloud service. Telemetry may observe logs/state only.
- **Userscripts Directory & Bundler (`~/projects/userscript-bundler/userscripts/`)**: All browser and webview userscripts (Gemini, Perplexity, YouTube, Control Center, etc.) live in `~/projects/userscript-bundler/userscripts/`. The auto-bundler (`watch-and-bundle.js` / `bundler.cjs`) builds them into `~/projects/userscript-bundler/compiled/`. - **AGY Proxy Architecture & Session Resume (`services/agy-proxy/proxy.py`)**: Local FastAPI OpenAI proxy (`http://localhost:8080`) bridging Hermes WebUI to the local `/Users/matt/.local/bin/agy` CLI binary using Google subscription quota. All `agy` and `gemini-*` models are STRICTLY HARD-LOCKED to `agy` CLI to prevent accidental Vertex API key billing. Session persistence is keyed by SHA256 of the anchor user/system message in `~/.hermes/agy_proxy_sessions.json` and passed via `agy --conversation <conv_id>` to resume threads seamlessly across turns. See `services/agy-proxy/README.md`.

- **Span-Only Styling Invariant for Markdown & `thread.md`:** All UI layouts, wrappers, bubbles, cards, and styling containers in `thread.md` and custom markdown viewers MUST use `<span>` tags exclusively (with `display: block;`, `white-space: pre-wrap;`, and inline CSS). Block tags like `<div>` or `<p>` are strictly prohibited. Multiline user inputs and paragraphs must use `<br>` or `<br><br>` tags within the `<span>` container so markdown parsers do not terminate inline styling spans prematurely.
- **Zero-Tolerance Secret Isolation & Redacted Thread Sync**: Agents are strictly prohibited from viewing, reading, or printing raw `.env` contents directly (e.g. `cat .env`, `view_file` on `.env`, `grep .env`). Safe environment checks MUST use `aios-env` (`scripts/env_guard.py`) to inspect key existence and classification metadata without exposing values. All thread synchronization pipelines (`scripts/export_recent_threads.py`, `scripts/gen_conversation_md.py`) pass markdown transcripts through `SecretSanitizer` (`scripts/sanitize_thread.py`) to redact known credentials and regex token patterns prior to staging. Staged secret leaks or `.env` files automatically abort preflight and pre-commit checks.
- **AI-OS Companion App App Nap Elimination & Webview Wake Protocol**: The companion app permanently disables macOS App Nap on startup via `NSProcessInfo beginActivityWithOptions:` and `caffeinate -s -i`. Intercepts `WindowEvent::CloseRequested` to hide rather than destroy windows, supports on-demand dynamic window recreation (`ensure_perplexity_window` / `ensure_gemini_window`), auto-navigates on URL mismatch, runs a 15s tokio background keepalive heartbeat to prevent WebKit WebProcess suspension, and provides `/api/wake` & `/api/health` endpoints used by `query_aios.js` for proactive client-side waking before queries.
- **Automated Planner Continuation & Truncation Stitching (`query_aios.js`)**: `query_aios.js` inspects responses with `checkIncompleteReason` for unclosed code fences (` ``` `), missing implementation steps in `--plan` mode, mid-sentence cutoffs, and token limit hints.
