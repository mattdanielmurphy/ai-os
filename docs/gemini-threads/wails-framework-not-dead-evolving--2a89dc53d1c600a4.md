## Gemini
**No, Wails is definitely not dead.** In fact, it is in the middle of a major generational shift.

The project is highly active, with the development team pushing near-nightly automated alpha releases for **Wails v3**.  
GitHub

The Status of Wails v3

While the stable version of Wails v2 continues to receive maintenance and bug fixes, the core focus has shifted to v3, which introduces substantial architectural overhauls:  
Wails v3

**True Multi-Window Support:** Moving away from v2's declarative single-window setup to a flexible procedural API.  
Wails v3

**Native System Tray Integration:** Built-in support for background apps, menu bars, and notification areas.  
Wails v3

**Revamped Build System:** Utilizing a more transparent setup backed by Taskfile, rather than an opaque internal CLI process.  
GitHub

**Experimental Mobile Support:** Initial tooling is landing to allow deploying the same Go codebase to iOS and Android.  
Wails

Why it might *look* quiet

If you are looking strictly at the stable v2 branch, updates have slowed down to focus on regressions and critical fixes. Because the team has been working on the v3 alpha for an extended period to ensure API stability and iron out edge cases across Windows, macOS, and Linux, the official "General Availability" (GA) release has taken longer than originally expected. However, many developers in the Go ecosystem are already running the v3 alpha in production.  
Reddit
