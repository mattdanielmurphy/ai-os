## Gemini

To restrict your script to only the internal keyboard, you need to add a conditions block to your manipulator. Karabiner-Elements allows you to filter devices based on their vendor_id and product_id.


For almost all Apple Silicon or modern Intel MacBooks, the internal keyboard is identified by its specific Apple vendor and product IDs.


The Updated Script
Insert the conditions array inside your manipulator as shown below:


{
    "description": "Grave to Left Shift when held, Backslash when tapped (Internal Keyboard Only)",
    "manipulators": [
        {
            "type": "basic",
            "from": {
                "key_code": "grave_accent_and_tilde",
                "modifiers": { "optional": ["any"] }
            },
            "to": [
                {
                    "key_code": "left_shift",
                    "lazy": true
                }
            ],
            "to_if_alone": [{ "key_code": "backslash" }],
            "conditions": [
                {
                    "type": "device_if",
                    "identifiers": [
                        {
                            "is_built_in_keyboard": true
                        }
                    ]
                }
            ]
        }
    ]
}


How to verify your specific device
While is_built_in_keyboard: true usually does the trick, some specific Mac models or custom setups might require explicit IDs. If the script above doesn't trigger, follow these steps:



* Open Karabiner-EventViewer (included with Karabiner-Elements).

* Go to the Devices tab.

* Locate your "Apple Internal Keyboard / Trackpad".

* Copy the vendor_id and product_id.

* Replace the is_built_in_keyboard line with:

* "vendor_id": 1452,

* "product_id": 641 (Note: These numbers are examples; use what you find in EventViewer).





Key Components

* device_if: This condition ensures the rule only fires if the input comes from a device matching your criteria.

* is_built_in_keyboard: A shorthand property that targets the internal chassis keyboard across most MacBook generations.
