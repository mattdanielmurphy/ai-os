## Gemini

The behavior you are seeing—where double-tapping the top area or status bar of an app shrinks it or toggles fullscreen—is tied directly to iPadOS's multitasking windowing system.


Here is how you can manage this from both a user standpoint and within your own Swift app's code.



1. Disabling It System-Wide (As a User)
There is no surgical toggle to turn off only the double-tap gesture while keeping windowing intact. The gesture belongs to the window controls (the multitasking handle). To disable it universally across iPadOS, you have to revert the iPad to traditional single-app fullscreen mode.



* Open the Settings app on your iPad.

* Navigate to Multitasking & Gestures.

* Under the layout options, select Full Screen Apps.



Note: Switching to "Full Screen Apps" will turn off Stage Manager and Windowed Apps/Split View multitasking. The multitasking handle at the top will disappear, which natively eliminates the double-tap toggle behavior across all apps.




2. Disabling It inside Your Swift App (As a Developer)
If you want to prevent your app's window from resizing or exiting fullscreen when a user interacts with the top window bar, you must explicitly tell iPadOS that your application only supports fullscreen mode.


By declaring that your app does not support multitasking resizing, iPadOS removes the window control handles for your app, rendering the double-tap behavior inert.


Via Info.plist (The Standard Way)
You can restrict multitasking support globally for your app by adding specific keys to your property list:



* Open your project in Xcode.

* Select your Info.plist file (or go to your Target's Info tab).

* Add the key UIRequiresFullScreen (clean text: Requires full screen) and set its value to YES (true).


<key>UIRequiresFullScreen</key>
<true/>

Via SwiftUI App Lifecycle
If you are using a pure SwiftUI lifecycle and want to enforce this presentation, you can control the window behavior using WindowGroup presentation styles, though UIRequiresFullScreen in the plist remains the most ironclad restriction for iPadOS windowing. For specific scenes where you want to suggest fullscreen pinning, you can use:


import SwiftUI

@main
struct MyApp: App {
    var body: some Scene {
        WindowGroup {
            ContentView()
        }
        // Hinting to the system to avoid multi-window placement where supported
        .windowResizability(.contentSize) 
    }
}

Via UIKit / SceneDelegate
If your app uses a SceneDelegate, you can explicitly set the geometry preferences to emphasize fullscreen constraints when the window scene initializes:


func scene(_ scene: UIScene, willConnectTo session: UISceneSession, options connectionOptions: UIScene.ConnectionOptions) {
    guard let windowScene = (scene as? UIWindowScene) else { return }
    
    // Requesting the system to keep the space dedicated to this window
    let geometryPreferences = UIWindowScene.GeometryPreferences.iOS()
    windowScene.requestGeometryUpdate(geometryPreferences)
}

Setting UIRequiresFullScreen in your Info.plist is the most reliable approach; it tells iPadOS from launch that your app shouldn't be dynamic, removing the window frame controls that trigger the toggle.
