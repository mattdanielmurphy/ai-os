## Gemini

To put these equations into standard form for an ellipse, you need to set the right side of the equation to 1 by dividing the entire equation by the constant term.


1. The Red Ellipse
Given:
$$16x^2 + y^2 = 64$$


Divide every term by 64:
$$\frac{16x^2}{64} + \frac{y^2}{64} = \frac{64}{64}$$


Simplify the fractions:
$$\frac{x^2}{4} + \frac{y^2}{64} = 1$$


In the standard form $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$, this is:
$$\frac{x^2}{2^2} + \frac{y^2}{8^2} = 1$$



2. The Blue Ellipse
Given:
$$9x^2 + 25y^2 = 225$$


Divide every term by 225:
$$\frac{9x^2}{225} + \frac{25y^2}{225} = \frac{225}{225}$$


Simplify the fractions:
$$\frac{x^2}{25} + \frac{y^2}{9} = 1$$


In standard form, this is:
$$\frac{x^2}{5^2} + \frac{y^2}{3^2} = 1$$
