Question 2
Question: Solve this problem algebraically, using your knowledge of derivatives. Do not solve by graphing. What is the absolute maximum of the function $f(x) = \frac{3}{x+9}$ on the domain $[-17, -11]$?


Options:



* $-3/8$

* No absolute Maximum on the given domain.

* $-3/2$

* $-3/14$


Work:
$$f'(x) = \frac{-3}{(x+9)^2}$$
$f'(x) < 0$ for all $x \neq -9$. The function is strictly decreasing on $[-17, -11]$.
Absolute maximum occurs at the left endpoint, $x = -17$:
$$f(-17) = \frac{3}{-17+9} = \frac{3}{-8} = -\frac{3}{8}$$


Correct Answer: $-3/8$ (1st choice)



Question 3
Question: Given the derivative of a continuous function, $f'(x) = \frac{x^2 - 10x + 25}{x + 8}$, if each of the critical points and key values of the function were ADDED together, their SUM total would be:


Options:



* $-8$

* $5$

* $-3$

* $0$


Work:
Numerator: $x^2 - 10x + 25 = (x - 5)^2 = 0 \implies x = 5$
Denominator: $x + 8 = 0 \implies x = -8$
Sum of critical points and key values: $5 + (-8) = -3$


Correct Answer: $-3$ (3rd choice)



Question 4
Question: If an object's position over time is given by the function $d(t) = (t^2 + 2)e^{-\frac{t}{5}}$ for $t > 0$, on what interval is the object's position decreasing and concave up?


Options:



* $(0, 0.20)$

* $(0.20, 3.07)$

* $(3.07, 9.80)$

* $(9.80, 16.93)$


Work:
$$d'(t) = 2te^{-\frac{t}{5}} - \frac{1}{5}(t^2+2)e^{-\frac{t}{5}} = -\frac{1}{5}(t^2 - 10t + 2)e^{-\frac{t}{5}}$$
Decreasing where $d'(t) < 0 \implies t^2 - 10t + 2 > 0 \implies t > 9.80$ (for $t > 5$)


$$d''(t) = -\frac{1}{5}(2t - 10)e^{-\frac{t}{5}} + \frac{1}{25}(t^2 - 10t + 2)e^{-\frac{t}{5}} = \frac{1}{25}(t^2 - 20t + 52)e^{-\frac{t}{5}}$$
Concave up where $d''(t) > 0 \implies t^2 - 20t + 52 > 0 \implies t < 3.07$ or $t > 16.93$


Intersecting decreasing ($t > 9.80$) and concave up ($t < 3.07$ or $t > 16.93$) for the given options: $(9.80, 16.93)$


Correct Answer: $(9.80, 16.93)$ (4th choice)

Question 5
Question: True or False (Mean Value Theorem): For the function $f(x) = \sqrt{9x + 6}$ on the interval $[0,10]$. If $f'(c) = \frac{f(b) - f(a)}{b - a}$, then $c = 3.50$


Options:



* True

* False


Work:
$a = 0, b = 10$
$f(0) = \sqrt{6}$
$f(10) = \sqrt{96} = 4\sqrt{6}$
$\frac{f(10) - f(0)}{10 - 0} = \frac{4\sqrt{6} - \sqrt{6}}{10} = \frac{3\sqrt{6}}{10}$
$f'(x) = \frac{9}{2\sqrt{9x + 6}}$
$\frac{9}{2\sqrt{9c + 6}} = \frac{3\sqrt{6}}{10} \implies \sqrt{9c+6} = \frac{90}{6\sqrt{6}} = \frac{15}{\sqrt{6}}$
$9c+6 = \frac{225}{6} = 37.5 \implies 9c = 31.5 \implies c = 3.5$


Correct Answer: True (1st choice)



Question 6
Question: True or False, $\lim_{x \to 0} \frac{\ln(3x + 1)}{10e^x - 10} = 0$


Options:



* True

* False


Work:
Limit is indeterminate form $\frac{0}{0}$. Use L'Hôpital's Rule:
$\lim_{x \to 0} \frac{\frac{3}{3x + 1}}{10e^x} = \frac{3/1}{10(1)} = \frac{3}{10} \neq 0$


Correct Answer: False (2nd choice)



Question 7
Question: A ball is being inflated such that the volume is increasing at a constant rate of $140\text{ cm}^3/\text{s}$. How fast is the radius changing when the radius is $8\text{ cm}$? (Use $\pi \approx 3.14$)


Options:
[No options listed, numeric input box provided]


Work:
$V = \frac{4}{3}\pi r^3 \implies \frac{dV}{dt} = 4\pi r^2 \frac{dr}{dt}$
$140 = 4(3.14)(8^2) \frac{dr}{dt}$
$140 = 803.84 \frac{dr}{dt}$
$\frac{dr}{dt} = \frac{140}{803.84} \approx 0.17416$


Correct Answer: 0.17



Question 8
Question: True or False, If $f'(6) = f''(6) = 0$, then $x = 6$ MUST be an inflection point.


Options:



* False

* True


Work:
Counterexample: $f(x) = (x-6)^4$.
$f'(x) = 4(x-6)^3 \implies f'(6)=0$
$f''(x) = 12(x-6)^2 \implies f''(6)=0$
Since $f''(x) \ge 0$ for all $x$, the concavity does not change at $x=6$.


Correct Answer: False (1st choice)
