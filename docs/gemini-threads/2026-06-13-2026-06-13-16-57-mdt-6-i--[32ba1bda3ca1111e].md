Here is how to safely find and clear out the space.



1. Find the Biggest Culprits
Before deleting anything, identify what is eating up the 45 GB. Run this command to list the largest directories in your root, sorted by size:

Depending on what the du command reveals, here are the most common ways to reclaim space safely:

Ubuntu/Debian systems keep copies of downloaded .deb files. Clear them out:


sudo apt-get clean
sudo apt-get autoremove --purge

Vacuum Systemd Journal Logs
System logs can accumulate indefinitely if not rotated. Check their size and shrink them down to the last 3 days:


sudo journalctl --disk-usage
sudo journalctl --vacuum-time=3d

Clear /var/log (The Careful Way)
If /var/log is massive, look for old, compressed log files (ending in .gz or .1) and remove them.

3. A Critical Warning on "Deleted" Files

If you delete files but df -h doesn't show any reclaimed space, run this to find deleted but open files:


sudo lsof +L1

If you see a service holding onto a massive deleted file, restarting that specific service (e.g., sudo systemctl restart nginx) will finally release the space.
