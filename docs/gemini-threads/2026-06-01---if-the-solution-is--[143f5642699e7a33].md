Options: * true



* false


Correct Answer: true (1st choice)



Explanation
To apply the Intermediate Value Theorem (IVT), two conditions must be met:



* The function $f(x) = 3x^2 - x - 2$ must be continuous on the closed interval $[0, 2]$. Since it is a polynomial, it is continuous everywhere.

* The target value (0) must lie between the values of the function at the endpoints, $f(0)$ and $f(2)$.


Evaluating the endpoints:



* $f(0) = 3(0)^2 - 0 - 2 = -2$

* $f(2) = 3(2)^2 - 2 - 2 = 12 - 4 = 8$


Since $f(0) = -2$ (negative) and $f(2) = 8$ (positive), the number 0 lies between $-2$ and $8$. Therefore, by the IVT, there must be at least one value $c$ in the interval $[0, 2]$ such that $f(c) = 0$.
