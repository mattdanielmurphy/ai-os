To find the equation of the line passing through $(-1, 5)$ and $(3, 17)$, you can follow these steps:


1. Find the Slope ($m$)
The formula for slope is:
$$m = \frac{y_2 - y_1}{x_2 - x_1}$$


Plugging in your coordinates:
$$m = \frac{17 - 5}{3 - (-1)} = \frac{12}{4} = 3$$


2. Find the $y$-intercept ($b$)
Use the slope-intercept form, $y = mx + b$, and plug in one of your points (e.g., $(-1, 5)$):
$$5 = 3(-1) + b$$
$$5 = -3 + b$$
$$8 = b$$


3. Write the Equation
Combining the slope and the $y$-intercept gives you:
$y = 3x + 8$

Actually, the correct answer for this one is $x \geq 0$.


Here is why:


The rule for inverse functions is that the domain of the inverse is exactly the same as the range of the original function.


1. Find the Range of $f(x)$
The original function is $f(x) = \sqrt{x - 2}$.



* The smallest value a square root can produce is 0 (when $x = 2$).

* As $x$ increases, the result of the square root keeps getting larger.

* Therefore, the range of $f(x)$ is $[0, \infty)$ or $y \geq 0$.


2. Determine the Domain of the Inverse
Since the range of the original is $y \geq 0$, the domain of its inverse must be $x \geq 0$.



Common Pitfall:
It is easy to accidentally find the domain of the original function ($x \geq 2$) instead of the domain of the inverse. If you were to solve for the inverse equation, you would get $f^{-1}(x) = x^2 + 2$, which looks like it could take any number, but it is restricted to $x \geq 0$ to stay a valid inverse of the square root function.

To solve the equation $\log_3 x = \log_3 2 + \log_3 3$, you can use the product rule for logarithms.


1. Combine the right side
The product rule states that $\log_b(M) + \log_b(N) = \log_b(M \cdot N)$. Since the bases are the same, you can multiply the arguments:
$$\log_3 x = \log_3 (2 \cdot 3)$$
$$\log_3 x = \log_3 6$$


2. Solve for $x$
Since the logarithms on both sides have the same base ($3$), their arguments must be equal:
$$x = 6$$
