Under the General Data Protection Regulation (GDPR), companies are not required to provide a "self-serve" automated portal for every specific right, including the Right of Access (Article 15).


What the law mandates is that the controller must facilitate the exercise of data subject rights. This means they must provide a way for you to make a request and receive a response within the statutory timeframes (usually one month, though this can be extended for complex cases).


The distinction between "self-serve" and "formal request" is a matter of administrative preference for the service provider:



* Self-Serve: Companies often build automated tools for common, high-volume tasks (like downloading an archive of your data or deleting an account) because it is more efficient for them and immediate for the user.

* Formal Requests: When a feature isn't automated, the company is still legally obligated to process the request manually via their support, privacy, or legal teams.


In short, they do not have to provide a "button" for everything, but they do have to provide a functional mechanism—such as a designated email address or a privacy request form—to ensure your right to access your personal data is honored when you ask for it. The help article indicates that while they lack an automated self-serve button for access, they maintain a process for handling these as formal GDPR requests.

Option 2: Native "Do-It-Yourself" (No Third-Party App)
If you prefer to avoid third-party software, you can create your own "New File" command using Automator or the Shortcuts app.


Using Shortcuts (Recommended for flexibility):



* Open the Shortcuts app and click the + icon to create a new shortcut.

* Search for the Run AppleScript action and drag it into the workspace.

* Paste the following code into the script block:
tell application "Finder"
    set currentFolder to (target of front window) as alias
    set newFile to make new file at currentFolder with properties {name:"untitled.txt"}
    select newFile
end tell



* Click the Info icon (top right) and check Use as Quick Action. Ensure "Finder" is selected as the application.

* You can now right-click any folder, go to Quick Actions, and select your new shortcut to create a text file. You can also assign a custom keyboard shortcut to it in System Settings > Keyboard > Keyboard Shortcuts > Services.
