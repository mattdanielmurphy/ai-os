Algebraic Verification
A limit exists if the function approaches a single, finite value from the specified direction.


I. Left-Hand Limit
$$\lim_{x \to 2^-} f(x) = L_1$$
As $x$ approaches $2$ from the left, the graph approaches the $y$-value of the open circle. Since this is a finite value, the limit exists.


II. Right-Hand Limit
$$\lim_{x \to 2^+} f(x) = L_2$$
As $x$ approaches $2$ from the right, the graph approaches the $y$-value of the solid dot. Since this is a finite value, the limit exists.


III. Two-Sided Limit
$$\lim_{x \to 2} f(x) \text{ exists only if } \lim_{x \to 2^-} f(x) = \lim_{x \to 2^+} f(x)$$
Observing the graph:



* $L_1 \neq L_2$ (there is a jump discontinuity).

* Therefore, the two-sided limit does not exist.
