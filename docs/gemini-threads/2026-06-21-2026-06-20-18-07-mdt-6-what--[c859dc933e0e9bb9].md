## Gemini

Google API keys typically start with specific string prefixes depending on the type of key generated:



* AIza – This is the standard, most common prefix for classic traffic/browser API keys (e.g., Google Maps, YouTube, Firebase, and legacy Google Cloud keys).

* AQ or AQ. – Google has been transitioning towards these more secure "Authentication Keys" (such as those generated via Google AI Studio for the Gemini API).


A standard Google API key structure usually looks something like: AIzaSy... or AQ.Sy... followed by a long, randomized string of alphanumeric characters and symbols.

Warning: This lets the underlying models execute commands and modify files instantly without asking for your approval first.


2. The Configuration Command (Fine-Grained YOLO)
If you don't want to pass a flag every time, you can permanently alter how permissions are handled via the configuration menu:

* Change the setting from request-review (the default) to always-proceed.


You can also achieve this by opening your global settings.json file (typically located at ~/.gemini/antigravity-cli/settings.json) and updating the permissions field to allow automated execution.
