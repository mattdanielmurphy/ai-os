## Gemini

In calculus, DNE stands for Does Not Exist.


It is used to describe a situation where a function does not approach a single, finite, and consistent value as $x$ gets closer to a specific point.


There are three common reasons why a limit might be "DNE":



* Left-hand and right-hand limits disagree: If you approach a point from the left and get one value, but approach from the right and get a different value, there is a "jump" in the graph, so the overall limit does not exist.

* Vertical Asymptotes (Unbounded behavior): If the function shoots off toward positive or negative infinity (like the behavior you saw at $x = -1$ in your exercise), the limit does not exist because infinity is not a specific finite number.

* Oscillation: If the function oscillates rapidly as it approaches a point (such that it never settles on a single value), the limit does not exist.


Regarding your last point, "not defined" and "DNE" are often used interchangeably in the context of limits. In your specific problem, it says "not defined" at $x \to 5^+$ because the graph stops at $x = 5$; there is no function to the right of that point to analyze, so a right-hand limit cannot be calculated.

In a piecewise function:



* The first part, $y = \frac{x^4 - 1}{x - 1}$, is a curve that exists everywhere except at $x = 1$. If you look closely at the graph on your screen, there is a "hole" (or an open circle) at $x = 1$.

Essentially, the first part of the function creates the curve with a missing spot, and the second part "plugs" that hole with a single point.

In Desmos, enter these three lines:

* This connects the domain start (-3) to the jump at x=1 and passes through the zero at x=-2.




* For the jump/second section: y = x - 3 {1 <= x <= 5}

* This creates a second piece starting at x=1. Since the first piece ends at $y=3$ and this one starts at $y=-2$, the limit at $x=1$ is DNE.




* To force the limit at x=-2 to be 5: * Instead of a simple line, use a single point for that specific value: y = 5 {x = -2}

* Note: If you want the line to pass through a hole at (-2, 5) but have the value be 5, you would need to adjust the first equation to be a piecewise or simply accept that the line passes through it.






How to Graph in Desmos
To graph any custom piecewise function effectively, use the curly bracket syntax to define the "where" (the domain) for each "what" (the equation).



* Syntax: y = [Equation] {[Condition]}

* Multiple conditions: You can combine them using commas. For example: y = x^2 {-3 <= x < 0, x > 1} will graph a parabola only where $x$ is between -3 and 0, and again where $x$ is greater than 1.

* Adding Points: To plot a specific point, just type the coordinate: (1, 3). If you want it to look like a "hole" (open circle), click the icon to the left of the expression in the sidebar, long-press the color circle, and select the empty circle style.


Why this works

* Domain: The curly brackets restrict the graph to the specified range.

* Zeros: By using x + 2, the graph hits the x-axis exactly at x = -2.

* Limits: By defining two different lines that do not meet at $x = 1$, the left-hand limit ($y = 3$) and the right-hand limit ($y = -2$) are different, satisfying the condition that the limit DNE.
