## Gemini

Here are the most efficient ways to downscale a PDF on macOS, depending on whether you want a quick built-in option, a precise command-line tool, or a local script.


Method 1: The Built-in macOS Way (Preview)
Preview has a built-in export filter for reducing file size, though it offers limited control over the compression strength.



* Open the PDF in Preview.

* Go to File > Export... (not Export as PDF).

* In the Quartz Filter dropdown menu, select Reduce File Size.

* Choose your destination and save.



⚠️ Note: If the output looks too blurry, the default Apple profile is compressing it too aggressively. For better results, use one of the methods below.




Method 2: Command Line via Ghostscript (gs)
For precise control over quality and scaling without uploading your files to a server, Ghostscript is the industry standard. You can install it via Homebrew:


brew install ghostscript

Run the following command to compress your PDF. Adjust the -dPDFSETTINGS flag based on the quality you need:


gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 -dPDFSETTINGS=/ebook -dNOPAUSE -dQUIET -dBATCH -sOutputFile=output.pdf input.pdf

Quality Settings Reference:

* -dPDFSETTINGS=/screen – Low resolution, high compression (72 dpi). Best for quick mobile viewing.

* -dPDFSETTINGS=/ebook – Medium resolution, moderate compression (150 dpi). Ideal for standard digital reading and uploads.

* -dPDFSETTINGS=/printer – High quality (300 dpi). Best for physical printing.

* -dPDFSETTINGS=/prepress – Maximum quality preservation. Minimal compression.



Method 3: Using a Node.js Script (Local Developer Workflow)
If you prefer handling assets programmatically or need to process files in bulk, you can use a Node package like pdf-lib or run a child process that wraps Ghostscript.


If you already have Ghostscript installed on your machine, a quick exec script in Node can automate this:


import { exec } from 'child_process';
import path from 'path';

const compressPDF = (inputPath, outputPath, setting = 'ebook') => {
  const cmd = `gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 -dPDFSETTINGS=/${setting} -dNOPAUSE -dQUIET -dBATCH -sOutputFile="${outputPath}" "${inputPath}"`;
  
  exec(cmd, (error, stdout, stderr) => {
    if (error) {
      console.error(`Error: ${error.message}`);
      return;
    }
    if (stderr) {
      console.error(`Stderr: ${stderr}`);
      return;
    }
    console.log(`Successfully downscaled to ${outputPath}`);
  });
};

// Example usage
compressPDF('large-document.pdf', 'compressed-document.pdf', 'ebook');
