## Gemini

For a fast, reliable way to switch your audio to AirPods using a keyboard shortcut, you have two primary "pro" app options and a powerful CLI method if you want to integrate it into your existing automations.


1. ToothFairy (Best for Speed/Simplicity)
ToothFairy is a lightweight utility designed specifically for this. It adds an icon to your menu bar for each device (AirPods, Beats, etc.) and allows you to bind a global hotkey to connect/disconnect them.



* Speed: Near-instant. It forces a connection attempt and switches the audio output in one go.

* Key Feature: You can set it to ensure the "High Quality Codec" (AAC) is used for audio output, preventing macOS from switching to the lower-quality SCO codec if it thinks you're about to use the microphone.


2. AirBuddy (Best for Features)
AirBuddy brings the iOS-style "sliding card" to Mac when you open your AirPods case, but it also has robust shortcut support.



* Keyboard Shortcut: You can configure a global shortcut to "Connect to nearest headset" or a specific device.

* Shortcuts App Integration: It provides native actions for the macOS Shortcuts app (e.g., "Connect [AirPods Name]"), which you can then trigger with a key combo via System Settings.


3. The CLI Method (Best for Power Users)
Since you’re comfortable with the command line and automation tools like Keyboard Maestro or Hammerspoon, you can build your own for free using Homebrew.



* Install the utilities:
brew install bluetoothconnector switchaudio-osx



* The Script:
Find your AirPods' MAC address by running BluetoothConnector. Then, create a one-liner (or a script) like this:
# Connect and switch output
BluetoothConnector -c aa-bb-cc-dd-ee-ff --notify && SwitchAudioSource -s "Matthew's AirPods"



* Trigger: Bind this script to a shortcut in Hammerspoon or Keyboard Maestro.
