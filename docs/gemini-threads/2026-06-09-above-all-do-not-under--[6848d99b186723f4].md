## Gemini

You can trigger a macOS shortcut via URL using Apple's native shortcuts:// URL scheme. This works inside web browsers, the command line, or third-party launchers like Karabiner-Elements, Keyboard Maestro, or Raycast.


1. Basic Execution
To trigger a shortcut by its exact name, use this structure:


shortcuts://run-shortcut?name=YourShortcutName

Note: The name must be URL-encoded. For example, if your shortcut is named My Daily Routine, spaces become %20:


shortcuts://run-shortcut?name=My%20Daily%20Routine

2. Passing Input & Text
If your shortcut accepts text inputs, you can append input and text parameters to the query string:



* Passing a text string:
shortcuts://run-shortcut?name=Log%20Note&input=text&text=Hello%20World



* Passing your current clipboard contents:
shortcuts://run-shortcut?name=Process%20Text&input=clipboard




3. Alternative: Using x-callback-url
If you want the focus to return to the calling application or handle successful/failed execution programmatically, use the x-callback-url standard:


shortcuts://x-callback-url/run-shortcut?name=YourShortcutName


Command Line / Scripting Usage
If you are running this from a shell script or a wrapper terminal command, you can trigger the URL scheme using the open command:


open "shortcuts://run-shortcut?name=YourShortcutName"


Pro-Tip on App Focus: Executing a shortcut via a URL scheme will naturally bring the Shortcuts app to the foreground. If you are triggering it programmatically in the background and want to avoid the UI pop-up entirely, running it via AppleScript or a shell wrapper is usually cleaner:


shortcuts run "YourShortcutName"
