## Gemini

You are absolutely correct to be precise here.


In physics notation, the "i" typically stands for a variable (representing "initial"), while "bike" is the descriptive label. Therefore, the "i" should remain italicized as a variable, and the descriptive label should be in upright (roman) font.


The most rigorous way to typeset this is:


$$\vec{p}_{i\text{-bike}}$$


Using \text{-} or \mathrm{-} ensures the dash is also upright, clearly separating the variable from the descriptor. If you are using software like LaTeX (or a system that supports it), you would write it as \vec{p}_{i\text{-bike}}. This clearly communicates that $i$ is the initial state and "bike" is the object, maintaining proper mathematical typography.
