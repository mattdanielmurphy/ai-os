## Gemini

They describe the exact same direction, but $11^\circ$ N of E (North of East) is significantly more common in physics and navigation.


Here is why:


1. The Standard Reference Angle
In standard navigation and physics, directions are typically measured relative to the closest primary compass point (North, South, East, or West). Because $11^\circ$ is a small, sharp angle, it is much more natural to start at East and look $11^\circ$ toward the North.


Using $79^\circ$ E of N is technically correct, but starting at North and swinging almost a full quadrant ($79^\circ$) toward East is less intuitive to visualize.


2. Standard Mathematical Form (Cartesian Planes)
In mathematics and physics problems, angles are generally measured counterclockwise from the positive x-axis (which represents East).



* $11^\circ$ N of E aligns perfectly with this standard $11^\circ$ angle in the first quadrant.

* It keeps the numbers small and easy to work with when breaking vectors down into $x$ (cos) and $y$ (sin) components.

Here is what that "one-shot" Python script would look like. You can save this locally and run it in an environment where you've installed the dependencies:


import cv2
import numpy as np
# Assuming geocalib is cloned/installed locally
from geocalib import GeoCalib 

def fix_deceptive_photo(image_path, output_path):
    # 1. Load the real estate image
    img = cv2.imread(image_path)
    h, w = img.shape[:2]

    # 2. Initialize the ML Analyzer
    # (Extracts camera intrinsics K and rotation matrix R based on scene geometry)
    calibrator = GeoCalib()
    calibration_result = calibrator.localize(img)
    
    # Extract the intrinsic camera matrix (contains focal lengths fx, fy and center cx, cy)
    K = calibration_result['K'] 
    fx = K[0, 0]
    fy = K[1, 1]
    cx = K[0, 2]
    cy = K[1, 2]

    # 3. The Non-AI Corrector: Cylindrical Projection Maps
    # We build a lookup table mapping every pixel to a cylindrical surface
    map_x = np.zeros((h, w), dtype=np.float32)
    map_y = np.zeros((h, w), dtype=np.float32)

    for y in range(h):
        for x in range(w):
            # Convert pixel coordinates to angles relative to camera center
            theta = (x - cx) / fx
            h_cyl = (y - cy) / fy
            
            # Project back to flat image plane coordinates
            x_rect = fx * np.tan(theta) + cx
            y_rect = fy * (h_cyl / np.cos(theta)) + cy
            
            map_x[y, x] = x_rect
            map_y[y, x] = y_rect

    # 4. Remap the pixels with zero-guessing interpolation
    corrected_img = cv2.remap(img, map_x, map_y, interpolation=cv2.INTER_LINEAR, borderMode=cv2.BORDER_CONSTANT, borderValue=(0,0,0))

    # 5. Save the mathematically honest image
    cv2.imwrite(output_path, corrected_img)
    print(f"Corrected image saved to {output_path}")

# Example usage:
# fix_deceptive_photo('stretched_living_room.jpg', 'honest_living_room.jpg')

Why this is an easy one-shot for code generation:

* Clear data handoff: Step 1 outputs a simple 3x3 matrix array of numbers ($K$). Step 2 just takes those exact numbers and feeds them into standard trigonometry equations.

* Deterministic math: The pixel remapping (cv2.remap) doesn't require any branching logic or conditional edge-cases. It just loops through the matrix and shifts coordinates.

2. The Processor Script (undistort.py)
Save this file in the root of the geocalib directory. It handles the pipeline from deep learning inference to the deterministic pixel remapping.


import argparse
import sys
from pathlib import Path
import cv2
import numpy as np

try:
    from geocalib import GeoCalib
except ImportError:
    print("Error: GeoCalib module not found. Ensure you are running this inside the activated virtual environment.")
    sys.exit(1)

def run_pipeline(input_path: str, output_path: str, scale: float):
    if not Path(input_path).is_file():
        print(f"Error: Could not find input file '{input_path}'")
        sys.exit(1)

    print(f"Loading image: {input_path}...")
    img = cv2.imread(input_path)
    if img is None:
        print("Error: OpenCV failed to decode the image.")
        sys.exit(1)

    h, w = img.shape[:2]

    print("Initializing GeoCalib model...")
    # Initialize the model (will download weights on first run)
    calibrator = GeoCalib()

    print("Analyzing structural geometry...")
    # localization returns a dict containing the K matrix and gravity rotation
    result = calibrator.localize(img)
    
    K = result['K']
    fx = K[0, 0]
    fy = K[1, 1]
    cx = K[0, 2]
    cy = K[1, 2]

    print(f"Detected Focal Length (px): fx={fx:.2f}, fy={fy:.2f}")

    # Build the cylindrical mapping
    print("Computing zero-guessing cylindrical projection map...")
    
    # We apply a scale factor to control the 'zoom' of the final viewport
    # A scale of 1.0 matches the center pixels 1:1, but might result in black borders.
    f_out = fx * scale

    # Pre-allocate coordinate maps
    map_x = np.zeros((h, w), dtype=np.float32)
    map_y = np.zeros((h, w), dtype=np.float32)

    # Calculate coordinates relative to the output image center
    # using broadcasting for performance instead of nested for-loops
    y_coords, x_coords = np.indices((h, w), dtype=np.float32)
    
    # Angular coordinates for the cylinder
    theta = (x_coords - (w / 2)) / f_out
    h_cyl = (y_coords - (h / 2)) / f_out

    # Project angles back to the flat, original image sensor space
    orig_x = fx * np.tan(theta) + cx
    orig_y = fy * (h_cyl / np.cos(theta)) + cy

    map_x[:] = orig_x
    map_y[:] = orig_y

    print("Executing geometric remap...")
    # INTER_CUBIC gives a slightly sharper result than linear when stretching pixels
    corrected_img = cv2.remap(
        img, 
        map_x, 
        map_y, 
        interpolation=cv2.INTER_CUBIC, 
        borderMode=cv2.BORDER_CONSTANT, 
        borderValue=(0, 0, 0)
    )

    cv2.imwrite(output_path, corrected_img)
    print(f"Success! Un-stretched image saved to: {output_path}")

def main():
    parser = argparse.ArgumentParser(description="Correct wide-angle real estate distortion using GeoCalib and OpenCV.")
    parser.add_argument("input", help="Path to the input stretched image")
    parser.add_argument("-o", "--output", default="corrected_output.jpg", help="Path for the output image (default: corrected_output.jpg)")
    parser.add_argument("-s", "--scale", type=float, default=1.0, help="Viewport scale/zoom factor. Try 1.2 or 0.8 to adjust the crop (default: 1.0)")
    
    args = parser.parse_args()
    run_pipeline(args.input, args.output, args.scale)

if __name__ == "__main__":
    main()
