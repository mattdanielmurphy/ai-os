Jargon Translation Sheet
As you start listening, you’ll hear these terms thrown around constantly. Here is the plain-English version of what they mean:



* Agent / Agentic: Standard AI is like a calculator—you type something, it responds, and it stops. An "agent" can run in a loop. You give it a goal (e.g., "Find a bug in this file and fix it"), and it can think, try a solution, check if it worked, and try again without you having to prompt it every single step of the way.

* Inference: Just a fancy word for the AI generating a response. When a model is "running inference," it's actively processing your prompt and spitting out tokens.

* Context Window: The AI's short-term memory. It's the total amount of text (both your prompt and its previous answers) the model can "hold in its head" at one exact moment.

* MCP (Model Context Protocol): Think of this as a universal adapter plug. It's a new standard that lets an AI model safely talk to external tools, your computer's file system, or databases without developers having to build custom bridges for every single app.


Start with an episode of Hard Fork to get comfortable with the current landscape, then check out Practical AI when you want to see how people apply it.
