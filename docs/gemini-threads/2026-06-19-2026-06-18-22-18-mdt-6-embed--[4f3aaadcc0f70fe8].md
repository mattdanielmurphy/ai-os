## Gemini

You cannot embed a raw .png file directly into HTML as plain binary text, but you can achieve the exact same result by converting the PNG into a Base64 data URI. This encodes the image data into a text string that browsers can read natively.


Here is how to do it and the trade-offs to keep in mind.



The Code Structure
Instead of pointing to an external file path in your src attribute, you paste the entire Base64 string directly into the HTML.


<img src="data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAUAAAAFCAYAAACNbyblAAAAHElEQVQI12P4//8/w38GIAXDIBKE0DHxgljNBAAO9TXL0Y4OHwAAAABJRU5ErkJggg==" alt="Red dot" />

You can also use this method inside your CSS for background images:


.hero-banner {
    background-image: url("data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAAAAU...[string continues]");
}


How to Convert a PNG to Base64
You don't have to write the string manually. You can generate it using standard terminal commands or online tools:



* Mac/Linux Terminal: base64 -i input.png

* Windows PowerShell: [Convert]::ToBase64String([IO.File]::ReadAllBytes("./input.png"))

* Web Tools: Search for any "PNG to Base64 converter," drop your file in, and copy the resulting data:image/png;base64,... string.



Pros and Cons of Inlining Images
Before converting all your graphics, weigh the performance impacts:























AdvantagesDisadvantagesFewer HTTP Requests: The browser doesn't have to fetch a separate file, which can speed up initial loading perception for tiny icons.Larger File Size: Base64 encoding increases the image file size by roughly 33% compared to the original binary PNG.Self-Contained Files: Perfect for single-file HTML templates, email newsletters, or offline documentation.No Browser Caching: The image cannot be cached independently of the HTML file. If a user visits multiple pages with the same image, they download it every time.Prevents Broken Links: The image lives inside the code, so it will never fail to load due to a missing asset folder.Messy Codebase: Large images generate hundreds of lines of text strings, making your HTML incredibly difficult to read and maintain.
Best Practice
Limit this technique to small icons, spinners, or logos (ideally under 5 KB). For standard photos or large graphics, traditional external linking (<img src="image.png">) remains the better choice for performance.
