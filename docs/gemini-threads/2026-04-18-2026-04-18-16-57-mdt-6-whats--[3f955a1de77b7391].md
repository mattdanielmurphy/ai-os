## Gemini

In a scientific context, it is most commonly called a figure caption or a figure legend. While "figure title" is sometimes used colloquially, the formal standard across most academic journals and textbooks is caption.


Standard Components
A scientific figure description typically includes three distinct parts:



* Figure Label: Usually bolded (e.g., Figure 1).

* Title/Descriptor: A brief, punchy sentence fragment describing what the figure is.

* Legend/Caption Body: A more detailed explanation that defines symbols, colors, error bars, and provides essential context so the image can be understood without reading the full text of the paper.



Comparison of Terms

























TermContextUsageCaptionGeneral ScienceThe entire block of text below the image.LegendData VisualizationSpecifically refers to the key that defines symbols or colors (e.g., "Red line = Control group").CreditPublishingCites the original source or photographer.

Note: In scientific formatting (like APA or Vancouver styles), the "title" for a Table actually goes above the table, whereas for a Figure, the caption almost always goes below the image.

## Gemini

When you drop the base font size to 10pt, LaTeX rendered via KaTeX or MathJax often looks spindly because math fonts (like Computer Modern) are naturally thinner than a robust sans-serif like Roboto.


To fix this, you should target the math containers in your CSS to give them a slight "bump" in scale and ensure they vertically align correctly with your text.


CSS Fix for LaTeX Scaling
Add this to your stylesheet to ensure the equations feel proportional to the 10pt Roboto text:


/* Target KaTeX or MathJax classes specifically */
.katex, .mjx-chtml {
  font-size: 1.15em !important; /* Bumps math roughly 15% larger than surrounding text */
  letter-spacing: 0.01em;
}

/* Ensure display equations have enough "breathing room" */
.katex-display, .mjx-display {
  margin: 1.2em 0 !important;
  padding: 8px 0;
}

/* Optional: slightly thicken the math lines if they look too faint */
.katex {
  -webkit-font-smoothing: antialiased;
  text-rendering: optimizeLegibility;
}

Why 1.15em?
Math characters often have more internal white space and thinner strokes than Roboto’s geometric letters. Setting them to 1.15em compensates for that visual weight difference without making the equations look unnaturally large.
