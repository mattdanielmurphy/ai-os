The **$2,000 USD/year Azure credit** is part of the **Microsoft for Nonprofits** program (validated through **TechSoup Canada**), rather than an add-on to the student subscription.

---

### 1. The 3 Microsoft Cloud Options

| Pathway | Value | What You Get / Verification | Quota / Model Reality |
| :--- | :---: | :--- | :--- |
| **A. Azure for Students** | **$100 USD** (One-time) | Verified via `@ualberta.ca` institutional email. | **Crippled Sandbox:** As you discovered, model access is heavily gated (only `4.1-mini`, `4.1-nano`, standard fine-tune tiers, embeddings, and legacy models). No flagship models. |

### 2. Can You "Stack" Them?
- **Within the same subscription:** No. Azure subscriptions are partitioned by billing type (Student vs. Non-Profit vs. Commercial/Pay-as-you-go). 
- **Across your portfolio:** Yes. You can maintain your personal student account for throwaway dev experiments while holding a dedicated **TechSoup-validated organization subscription ($2k/yr)** or **Founders Hub startup subscription ($1k–$5k)** to host actual workloads and access commercial model quotas.
