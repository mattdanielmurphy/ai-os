# Rules → hooks plan: the short version

Agents will load about 55 lines of rules instead of 17,000 words, and the rest arrives exactly when it's needed. First fixes: the school guard, and no more asking you for OKs agents don't need.

Six decisions you might want to veto:

1. **Details files only when a reply runs long.** Readthroughs and reels only when you ask.

2. **One "act or wait" rule replaces ten.** Pushes to main stop asking you (except the crossword).

3. **The four UI design steps become one:** three examples, you pick, then it's built.

4. **Learning runs weekly, not every turn,** with at most three rule changes for you.

5. **Agent edits in school folders ask you first.**

6. **Agent-written "beta" rules can run without your OK.** They only add reminders, are tagged and capped at five, and expire in three weeks.

Also added:

- **A local rules dashboard,** with switches in your Tweaks panel.

- **Coordinators send big asks to an advisor first.**
