# Rules → hooks plan: the short version

Agents will always load about 55 lines of rules instead of 17,000 words. Everything else arrives at the moment it matters. The first fixes are the school guard and stopping agents from asking OKs they don't need.

Five decisions you might want to veto:

1. **Details files are written only when a reply runs long.** Readthroughs and reels are made only when you ask.

2. **One "act or wait" rule replaces ten.** Agents wait only for new ideas, irreversible or public actions, real forks, and new visual directions. Pushes to main stop asking you (except the crossword).

3. **The four UI design steps become one.** You see three examples, pick one, then it gets built.

4. **The self-learning loop runs weekly, not every turn.** It sends you at most three rule changes to approve.

5. **Any agent edit in your school folders asks you first.**
